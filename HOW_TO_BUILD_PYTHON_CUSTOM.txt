This is how to build DuckDB (with the pieces that Python needs), 
then create a Python library that links to that build 
(Hopefully this allows for tinkering with build settings for Clickbench, which uses Python)

activate the virtual environment .venv
cd /Users/alex/Documents/DuckDB/duckdb_alex_repo/
SDKROOT="/Library/Developer/CommandLineTools/SDKs/MacOSX15.1.sdk" GEN=ninja BUILD_ICU=1 BUILD_TPCH=1 BUILD_JSON=1 make
cd tools/pythonpkg
DUCKDB_BINARY_DIR=/Users/alex/Documents/DuckDB/duckdb_alex_repo/build/release  python3 -m pip install . -v &> pip_install.log
